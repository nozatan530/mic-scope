# マイクでオシロ

スマホ・タブレット・PC のマイクで拾った音を、その場で波形として映す、中学・高校の理科「音」の学習用オシロスコープ。

🔗 **公開URL**: https://oscillo.meetupsensei.com/

## 概要

声・口笛・楽器の音をリアルタイムの波形で見て、音の高さ＝振動数、大きさ＝振幅、音色＝波形の形だと確かめられます。
一時停止して2本のカーソルで周期 T を測り、f = 1/T を自分で計算してから、アプリの推定値（Hz と音名）と答え合わせをします。
波形を棚に最大4枚置いて重ねて比べたり、「ラを2秒キープ」「1オクターブ上を出そう」などのお題に声で挑戦したりできます。
音は録音せず、端末の外にも送りません（端末の中で波形にするだけ）。

## 使い方

- 「マイクをオンにする」を押して、マイクの使用を許可する
- 声や楽器を鳴らして波形を見る。時間軸（1目盛り 0.5〜10 ms）と縦の拡大を切り替えられる
- 「一時停止」→ 青（A）と橙（B）の線を山と次の山に合わせて T を読む → f = 1/T を入力して「答え合わせ」
- 「棚に置く」で波形を保存し、棚で2枚選んで「重ねる」「上下に並べる」で比べる
- 「チャレンジ」で5つのお題に挑戦する

## 技術

- Vite + React + TypeScript、Tailwind CSS
- Web Audio API（getUserMedia → AnalyserNode）。振動数は自己相関で推定
- GitHub Pages でホスティング（GitHub Actions でビルド）
- カスタムドメイン: meetupsensei.com
