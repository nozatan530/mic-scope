# 検証レポート 2026-11-17

AI Studio から取り込んだ直後の、生徒向けに仕上げるための通しの確認。

## 方法

- 自動チェック：`npm run lint`（型チェック）・`npm run check:dsp`（計算の自己チェック 14項目）・`npm run build` すべて通過
- ブラウザ：開発サーバーを内蔵ブラウザで開き、`getUserMedia` を合成音（OscillatorNode）に差し替えて「マイク」として流し込んだ。振動数・波形（正弦波／方形波）・大きさをスクリプトで変えて、体験の流れを最初から最後までたどった
- 画面幅：360px（スマホ）・375px・768px（iPad）・1366px（Chromebook）
- スクリーンショット：同じフォルダの `2026-11-17-*.jpg / .png`（git には入れていない）

## OK

- スタート → 「マイクをオンにする」→ スコープへ。許可を拒否したときは「マイクの使用が許可されていません」と手順、「もう一度試す」ボタンが出る
- 440Hz で波形がトリガで止まって見え、大きさのバーが動く。Hz は最初「？？？ Hz」で隠れている
- 一時停止 → カーソル A・B で T = 2.3 ms → 435 Hz を入力 → 「ぴったり！」（自分 435.0 Hz／アプリ 440.0 Hz／ずれ 1.1%）、音名「ラ（A4）0セント」が出る
- 棚に2枚置く → 再読み込み後も残る（スタートに「棚に 2 件」）→ 2枚選んで重ねて比べる。表の振動数・音名・周期・大きさも正しい（220Hz → 4.55 ms、440Hz → 2.27 ms）
- チャレンジ5つすべて、合成音でクリアできることを確認
  - ラを2秒キープ（440Hz）、ドレミ（C4〜C5 の8音を順に）、1オクターブ上（440 → 880Hz）、大きさだけ変える（3.00倍 → 0.30倍）、なめらかな波（正弦波 100%）
  - 方形波ではなめらか度 82% で、クリアにならない（正しい）
- 4つの画面幅すべてで、横にはみ出す要素なし。コンソールエラーなし
- 通信先は localhost と Google Fonts（fonts.googleapis.com / fonts.gstatic.com）だけ。音のデータはどこにも送っていない
- `dist/` に `AIza` や `GEMINI` を含む文字列なし。Gemini API への通信なし（AI 機能なし）
- 個人情報：ログイン・名前欄なし。棚の名前欄に「名前や連絡先は書かない」の注意あり

## 要修正（この日の /build で修正済み）

- 一時停止したままチャレンジに移ると、止まった振動数でメーターが進み、**無音でもクリアになる** → 解析を常に動かすよう修正
- 棚の「比べる」で、先頭が 0 の交差から始まらない波形（方形波など）が左端に数サンプルしか描かれない → 最初の上向き交差でそろえるよう修正
- スマホでは周期 T の数値が波形から離れていて、カーソルを動かしながら見られない → 波形の上にも T を表示
- スマホで2枚目を選んでも「比べる」欄がカードの下に隠れる → 自動でスクロール
- チャレンジ一覧の「4つのお題」（実際は5つ）、メーターの「−0 セント」表示

## 気になる点（実機でしか確かめられないもの）

- **iPad Safari・Chromebook・Android でのマイク許可の流れ**：合成音の差し替えでは、OS やブラウザの許可ダイアログは通っていない
- **自動音量調整（AGC）などが本当に切れているか**：`?debug=1` で端末ごとに echoCancellation / noiseSuppression / autoGainControl の値を見る
- **声で使ったときのメーターの反応**（揺れすぎ・遅すぎがないか）と、声のように揺れる音でのトリガの見やすさ
- **音叉・鍵盤でのオクターブ違い**（220Hz や 880Hz と出ないか）
- 1366×768 では、一時停止後の f の入力欄が画面の下にあり、少しスクロールが要る（T は波形の上に出るので測定はできる）
- 棚の波形は 1目盛り＝2 ms で保存すると 20 ms ぶんだけなので、「共通の時間軸」を 5 ms・10 ms にすると右側が空く
