- うまくいった:
  - AI Studio の試作は、計算（自己相関・音名とセント・なめらか度）が指示書どおりで、自己チェック13項目が最初から全部 PASS だった。式と「計算の確かめ」を指示書に書いておく方法が今回も効いた
  - `getUserMedia` を合成音に差し替えると、振動数・波形（正弦波／方形波）・大きさをスクリプトで変えられ、5つのチャレンジすべてを自動で通せた。マイクのアプリでも「通しの利用テスト」ができた
  - 取り込み当日に、不具合修正・未使用パッケージ整理・GitHub Pages 公開・OGP・ファビコンまで終えた
- つまずいた:
  - **一時停止したままチャレンジに移ると、無音でもクリアになる**不具合があった。スコープの「一時停止」が、裏で共有している音の解析まで止めていて、別画面の判定が古い値で進んでいた。画面ごとに試すだけでは見つからず、「止めてから別の画面へ」という組み合わせで見つかった
  - **棚の「比べる」で波形がほとんど描かれない**不具合があった。ライブ表示用のトリガ関数（表示幅ぶん残る範囲の「最後の」交差を選ぶ）を、保存済みの短い波形のそろえにも使い回していた。正弦波では目立たず、方形波で初めて見えた
  - 内蔵ブラウザのペインが隠れていると `requestAnimationFrame` が1秒に1回ほどに落ち、チャレンジの秒数テストが当てにならなかった。テスト中だけ `setTimeout` に差し替えて回避
  - OGP の描画スクリプトで `const top` と書き、ブラウザの `window.top` とぶつかって何も描かれなかった
- 学びの目的に対して: 授業で使っていないので未評価。設計上は「Hz を隠して f = 1/T を自分で計算 → 答え合わせ」「高さと大きさを別々に変えるチャレンジ」が目的に沿っている。スマホで T を見ながらカーソルを動かせるようにしたのは、周期を読み取る目的に直結する改善だった
